# ציקו · Chico

עוזר קולי מבוסס Gemini. **רק מדברים איתו** — אין צ'אט, אין כפתורים, אין תפריטים.
לוחצים על העיגול, מדברים, והוא עונה בקול.

A voice-only AI companion powered by Gemini. **Talking is the entire app** — no chat box, no tools, no menus.

---

## מה הוא

- **בנוי בדמות ג'ארוויס** מאיירון מן — רגוע, מדויק, הומור יבש, תשובות קצרות.
- **עונה לשם ציקו** (Chico), בעברית ובאנגלית.
- **קול במבטא ברזילאי** — חם, מתנגן, לא ממהר.
- **עובר שפה איתך.** דיברת עברית, הוא עונה בעברית. עברת לאנגלית, הוא עובר איתך, בלי להעיר על זה.
- **שיחה רציפה.** אחרי שהוא מסיים לדבר הוא ממשיך להקשיב — אפשר פשוט להמשיך.
- **אפשר לקטוע אותו** באמצע משפט: לחיצה על העיגול משתיקה אותו ומחזירה לך את רשות הדיבור.
- **הוא זוכר את השיחה הנוכחית** — ולא שום דבר מעבר לה.

הוא לא מפעיל מכשירים, לא שולח הודעות, לא קובע תזכורות ואין לו גישה לאינטרנט. הוא בן שיחה, וזהו.

## הפעלה

### הדרך המהירה — קבצים סטטיים

```bash
git clone <repo> && cd -
npx serve .        # או כל שרת סטטי אחר
```

פותחים בדפדפן, נכנסים ל־⚙, מדביקים מפתח Gemini מ־[Google AI Studio](https://aistudio.google.com/apikey), ולוחצים על העיגול.
המפתח נשמר רק ב־`localStorage` של הדפדפן ולא נשלח לשום מקום חוץ מ־Google.

> חייב להיות `http://localhost` או `https://` — מיקרופון לא עובד מ־`file://`.

### הדרך הבטוחה — עם שרת

כדי שהמפתח לא ישב בדפדפן בכלל:

```bash
export GEMINI_API_KEY=...     # ראה .env.example
npm start                     # http://localhost:8787
```

השרת מגיש את האפליקציה ומעביר את הבקשות ל־Gemini עם המפתח מהצד שלו. האפליקציה מזהה אותו לבד ומסתירה את שדה המפתח.
Node 18+, בלי תלויות כלל.

## דפדפנים

זיהוי הדיבור נשען על `SpeechRecognition` של הדפדפן: **Chrome, Edge או Safari**.
בפיירפוקס האפליקציה תיטען ותודיע שאין זיהוי דיבור.

## הגדרות

| | |
|---|---|
| **קול** | ארבעה קולות Gemini. `Charon` (ברירת מחדל) הוא העמוק והרגוע. |
| **שפת דיבור** | מה שהמיקרופון מצפה לשמוע. התשובה תמיד בשפה שדיברת בה. |
| **שיחה רציפה** | הוא ממשיך להקשיב אחרי כל תשובה. כבוי — לחיצה לכל תור. |
| **כתוביות** | טקסט על המסך. כבוי — קול בלבד. |
| **שיחה חדשה** | מוחק את הזיכרון ומחזיר אותו למנוחה. |

## מבנה

```
index.html          המסך — עיגול, מצב, כתובית
assets/styles.css   העיצוב
src/config.js       האישיות של ציקו והנחיית המבטא
src/models.js       בחירת דגם Gemini דינמית
src/api.js          שיחה + הקראה מול Gemini
src/audio.js        ניגון PCM והאנרגיה שמניעה את העיגול
src/speech.js       מיקרופון → טקסט
src/app.js          הלולאה: מקשיב, חושב, מדבר, מקשיב
server/server.js    שרת אופציונלי שמחזיק את המפתח
```

### לכוונן את האישיות

`SYSTEM_PROMPT` ב־`src/config.js` הוא כל מה שציקו הוא. רוצה אותו פחות רשמי, יותר ציני, או עם שם אחר — זה המקום היחיד לשנות.

### לכוונן את המבטא

`VOICE_DIRECTION` באותו קובץ הוא ההנחיה שנשלחת למודל ההקראה לפני כל משפט. לחיזוק המבטא אפשר לכתוב שם `strong Brazilian accent`; להחלשה, `subtle`.

### דגמי Gemini

האפליקציה **לא מקבעת שמות דגמים.** בהפעלה הראשונה היא שואלת את ה־API אילו דגמים המפתח שלך מגיע אליהם ובוחרת את החדש ביותר לשיחה ואת דגם ההקראה המתאים, ושומרת את הבחירה ליממה. אם דגם הוצא משימוש והתקבל 404 — היא בוחרת מחדש לבד. כך היא לא נשברת כשגוגל מחליפה גרסאות.
